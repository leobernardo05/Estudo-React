# 🚀 Estudo React

Repositório criado para armazenar meus estudos e projetos desenvolvidos durante o aprendizado de React.js.

Os projetos abordam desde os conceitos iniciais até tópicos mais avançados, incluindo componentes, props, eventos, hooks, formulários, estilização e requisições HTTP.

# ▶️ Como executar os projetos

Clone o repositório:

```bash
git clone https://github.com/leobernardo05/Estudo-React.git
```

Acesse a pasta do projeto desejado:

```bash
cd nome-da-pasta
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```
